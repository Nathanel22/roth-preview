# ROTH – Designvorschau V0.5.4 (öffentliche Testkopie)

Statische Seite ohne Framework. Enthält bewusst keinen Namen, kein Foto und keine Kontaktdaten.
Die Seite ist per `noindex` für Suchmaschinen gesperrt.

Dateien: `index.html`, `css/style.css`, `js/main.js`, `.nojekyll`

## Auf GitHub Pages bereitstellen
1. Auf github.com ein neues Repository anlegen (z. B. `roth-preview`). Wichtig: Dieses Repository ist nur für die Testkopie.
2. «Add file» → «Upload files» und den gesamten Inhalt dieses Ordners hochladen (inklusive der Ordner `css` und `js` sowie `.nojekyll`). «Commit changes» klicken.
3. «Settings» → «Pages». Unter «Build and deployment»: Source «Deploy from a branch», Branch `main`, Ordner `/ (root)`, «Save».
4. Nach ein bis zwei Minuten erscheint oben die Adresse `https://<benutzername>.github.io/roth-preview/`. Diese Adresse im Safari auf iPhone und iPad öffnen.
5. Testende: «Settings» → «Pages» → Veröffentlichung entfernen oder das Repository löschen.
